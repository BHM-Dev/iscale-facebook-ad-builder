HOW TO USE THIS FILE
-----------------------------------------------------------------
1. Save a copy in the package's Drive folder. Name it so it ends in
   HANDOFF-MANIFEST.txt -- for example CA-PROVEN-HANDOFF-MANIFEST.txt
   (use the package/folder name at the front).
2. Fill in one block per ad. A block = one headline/body + the files that use it.
   Two sample blocks are below: an IMAGE block (1X1 + 9X16) and a VIDEO block
   (4X5 + 9X16). Delete the one you don't need, and replace every <placeholder>
   and every sample filename.
3. Filenames must match the file in the folder EXACTLY, including the extension.
   Copy the name from Drive; don't retype it.
4. Keep each label (PRIMARY TEXT, HEADLINE, DESCRIPTION, 1X1 IMAGE, 4X5 VIDEO ...)
   in capitals on its own line, with the value on the line(s) below it.
   Image blocks use 1X1 IMAGE / 9X16 IMAGE; video blocks use 4X5 VIDEO / 9X16 VIDEO.
5. One Meta button for the whole file. If one ad needs a different button, put it
   in its own package/file for now.
6. Save it to Drive. The Ad Builder picks it up on the next hourly sync. Then check
   the "Package health" button in the Drive library picker: if your package isn't
   listed, or shows a problem, tell Steve. (A paste-and-check box is coming; when it
   is live you'll paste the file there BEFORE saving.)
